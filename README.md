# Task Manager — Тапсырмаларды басқару жүйесі

## 1. Жоба туралы
Task Manager — пайдаланушыларға күнделікті тапсырмаларын басқаруға мүмкіндік беретін веб-қосымша. Жоба PHP және MySQL технологиялары арқылы әзірленеді.

## 2. Жобаның мақсаты
Тапсырмаларды қосу, өзгерту, жою және олардың орындалу күйін бақылау жүйесін жасау.

## 3. Негізгі мүмкіндіктері
- Пайдаланушыны тіркеу және жүйеге кіру
- Тапсырма қосу
- Тапсырмаларды көру, өзгерту және жою (CRUD)
- Тапсырмаларды іздеу және сүзу
- Тапсырмаларды санаттарға бөлу
- Деректерді MySQL-де сақтау

## 4. Қолданылатын технологиялар
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- DBeaver
- GitHub

## 5. Негізгі беттер
1. Басты бет — index.php
2. Тіркелу — register.php
3. Жүйеге кіру — login.php
4. Тапсырма қосу — tasks/create.php
5. Тапсырманы өзгерту — tasks/edit.php

## 6. Дерекқор кестелері
- users
- categories
- tasks

## 7. Қауіпсіздік
- Құпиясөзді хэштеу
- SQL сұраныстарында prepared statements қолдану
- Енгізілген деректерді тексеру
- Сессия арқылы пайдаланушыны тексеру
- Рұқсатсыз қол жеткізуден қорғау

## 8. Апталық жоспар
8-апта: Тақырыпты таңдау, беттерді жоспарлау, ER-диаграмма және GitHub репозиторийін дайындау.
### 9-апта бойынша есеп
**Тақырыбы: Пайдаланушы интерфейсін әзірлеу (Frontend)**

Осы аптада Task Manager жобасының интерфейсін әзірлеу жұмыстарын орындадым. Жобаның мақсаты — пайдаланушыларға күнделікті тапсырмаларын жоспарлауға және олардың орындалуын бақылауға көмектесетін веб-қосымша жасау.

Жобаны әзірлеу барысында HTML, CSS және JavaScript тілдерін қолдандым. HTML арқылы сайттың негізгі құрылымын жасап, басты бет, тіркелу беті, жүйеге кіру беті және тапсырмаларды басқару бөлімдерін дайындадым.

CSS көмегімен сайттың дизайнын жасадым. Интерфейсте ашық қызғылт және ақ түстерді қолдандым. Батырмалардың, формалардың және тапсырмалар бөлімінің сыртқы көрінісін реттеп, сайтты телефон экранына бейімдедім.

JavaScript арқылы сайттың негізгі функцияларын іске асырдым. Пайдаланушы тапсырма қоса алады, оны өшіре алады және орындалғанын белгілей алады. Сонымен қатар, тапсырмаларды атауы бойынша іздеу және орындалу күйіне қарай сүзу мүмкіндіктерін қостым. Тапсырмалар браузердің localStorage сақтау орнына сақталады.

Тіркелу және жүйеге кіру формаларына деректерді тексеру функцияларын енгіздім. Мысалы, тіркелу кезінде құпиясөздердің бірдей болуын тексеру қарастырылды. Қазіргі уақытта бұл формалар демонстрациялық түрде жұмыс істейді, ал нақты тіркелу жүйесі PHP және MySQL қосылғаннан кейін жасалады.

Жұмыс барысында жобаның файлдарын реттеп, HTML, CSS және JavaScript кодтарын бөлек файлдарға орналастырдым. Бұл кодтарды кейін өзгертуге және жаңа функциялар қосуға мүмкіндік береді.

**Қорытынды:** 9-аптада Task Manager веб-қосымшасының frontend бөлігін әзірледім. Сайттың негізгі беттерін жасап, дизайнын реттедім және тапсырмаларды басқарудың бастапқы функцияларын қостым. Келесі кезеңде жобаны PHP және MySQL арқылы дерекқормен байланыстыруға дайындық жасаймын.
